# Roadmap

## 已完成

- 使用真实 Bangumi token 在真实 Obsidian 库中测试完整同步流程。
- 改进 token 过期、权限不足、Bangumi API 限流等错误提示。
- 增加 token 获取页面、剪贴板填入和手动 `Test token` 辅助。
- 支持书籍、动画、音乐、游戏和三次元条目类型。
- 支持文件命名、存储逻辑和是否同步搁置/抛弃条目的设置。
- 基于 Bangumi `updated_at` 实现增量同步，并在本地文件缺失时补回。
- 增加 Daily Notes 同步块。
- 增加用户可编辑的 Markdown 条目笔记模板。
- 通过模板支持自定义 frontmatter 字段。
- 生成同步失败报告。
- 增加轻量测试，覆盖 Markdown 渲染、同步块合并、重复文件防护和误删文件补回。
- 增加发布打包说明、版本号更新脚本和社区插件发布 checklist。
- 记录移动端兼容性可能不佳，并建议移动端谨慎使用。

## 后续增强

- 提供更友好的自定义 frontmatter 字段 UI。
- 为想编辑部分生成内容的用户提供更安全的合并策略。
- 可选按状态、年份、标签或条目类型创建索引笔记。
- 如果之后有不需要用户管理 client secret 的公共客户端流程，再重新评估 OAuth 登录。
- 根据真实用户反馈继续调整默认模板和 Daily Note 同步格式。
